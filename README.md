# 📋 Task List App (`task-list-pv511`)

Застосунок списку завдань (Task List) на базі **React 19**, **TypeScript** та **Vite** з глобальною стилізацією. 

Реалізовано функціонал відповідно до **Інструкції №2 (Урок 7)**:
- 📦 **Стан завдань у `App.tsx`** із лінивою ініціалізацією з `localStorage`.
- 💾 **Автоматична синхронізація** стану з `localStorage` через `useEffect`.
- 🎛️ **Контрольована форма `TaskForm`**: поля вводу з прив'язкою `value` + `onChange`, «жива» валідація, блокування кнопки «Додати».
- 🎯 **Хук `useRef`**: автоматичне встановлення фокусу в поле вводу при відкритті сторінки та повернення фокусу після кожного додавання завдання.
- 📊 **Підрахунок статистики `Counter`**: динамічний розрахунок загальної кількості та виконаних завдань.

---

## 🏗️ Компонентна архітектура проєкту

```text
src/
├── types/
│   └── index.ts          # Моделі даних: Task, Priority
├── components/
│   ├── Header.tsx        # Шапка додатку з іконкою та заголовком
│   ├── TaskForm.tsx      # Контрольована форма додавання з useRef (фокус) та валідацією
│   ├── Counter.tsx       # Панель статистики (всього, в процесі, виконано, прогрес-бар)
│   ├── TodoList.tsx      # Контейнер списку завдань та стан порожнього списку (Empty State)
│   └── TodoItem.tsx      # Картка окремого завдання (пріоритети, чекбокс, видалення)
├── App.tsx               # Оркестратор стану tasks, localStorage та додавання нових задач
├── index.css             # Єдиний файл глобальних стилів
└── main.tsx              # Точка входу в застосунок
```

## 🚀 Команди для запуску

1. `npm install` — встановлення залежностей
2. `npm run dev` — запуск локального dev-сервера
3. `npm run build` — збірка проєкту
4. `npm run lint` — перевірка лінтером Oxlint
